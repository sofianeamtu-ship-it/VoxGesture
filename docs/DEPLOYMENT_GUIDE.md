## 1. Quick Browser Upload (Zero-Install Method)

1. Open [github.com/new](https://github.com/new) and log in.
2. Set repository name to: **`voxgesture`**.
3. Choose **Public** (required for free GitHub Pages).
4. Click **Create repository**.
5. Click **Add file** ➔ **Upload files**.
6. Open your local project folder:  
   👉 `C:\Users\user\.gemini\antigravity\scratch\voxgesture`
7. Drag and drop all project files and directories:
   * `index.html`
   * `css/`
   * `js/`
   * `ai-transparency/`
   * `docs/`
   * `README.md`
8. Type commit message: `feat: release VoxGesture competition prototype`.
9. Click **Commit changes**.

---

## 2. Enabling GitHub Pages (Making it Live on the Web)

1. In your GitHub repository, click **Settings** (top right gear).
2. On the left menu, click **Pages** (under *Code and automation*).
3. Under **Build and deployment**:
   * **Source**: `Deploy from a branch`
   * **Branch**: `main` (or `master`)
   * **Folder**: `/(root)`
4. Click **Save**.
5. Wait 60 seconds and refresh. Your live URL will appear:  
   `https://<your-username>.github.io/voxgesture/`

1. Copy your live URL: `https://<your-username>.github.io/voxgesture/`.
